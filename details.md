# Final Project Details — CS5100

## Final Submission

The final submission must include both a **code component** and a **written paper**, weighted equally for the final grade.

### Code

- Written in Python (unless otherwise discussed with the instructor)
- May use any Python packages or external software, with proper citations
- Encouraged to use course packages (Gymnasium, PyTorch) where applicable
- Submit as a zip file or GitHub repository
- Must include all code: data cleaning, pre-processing, testing, etc.
- Must be well-organized and thoroughly commented

### Paper

The paper should be organized like a scientific paper and include the following sections:

- **Introduction:** Thorough description of the problem, background, history, and theory. Must cite and discuss at least one relevant academic paper.
- **Methods:** Explanation of the approach taken, evaluation methods, and any external data or software used.
- **Results:** Discussion of outcomes from the methods described, including numerical results or sample outputs as appropriate.
- **Conclusions:** Strengths and weaknesses of the approach, comparisons to other methods, and potential future improvements.
- **Works Cited:** Full bibliography including all cited articles, data sources, and software.

Writing style should match academic articles — full paragraphs, no bullet-pointed lists. Expected length: roughly **10 pages double-spaced** (no strict minimum or maximum).

---

## Grading Criteria

| Factor | Description |
|---|---|
| **Introduction & Background** | Clearly and accurately presents the topic; discusses prior work with at least one valid academic citation. A missing or fabricated citation results in a 0 for this section. |
| **Methods** | Appropriate methods, correctly implemented, accurately and thoroughly described. |
| **Evaluation** | Fully evaluates the system using relevant metrics and baselines; discusses strengths and weaknesses. |
| **Complexity** | Addresses an appropriately challenging problem with a sophisticated approach (3× programming assignment standard). |
| **Completeness & Clarity** | All code included; all paper sections present with proper citations; code and paper clearly written and well-commented. |
